# GETFLIX 🎬

GETFLIX is a Netflix-inspired streaming platform clone built using HTML, CSS, and JavaScript.

## Features 🚀

- Login Page
- Responsive Homepage
- Search Bar
- Profile Popup
- Settings Popup
- Logout Functionality
- Movie & Anime Sections
- Hover Effects
- External Streaming Links

## Technologies Used 💻

- HTML5
- CSS3
- JavaScript

## How to Run ▶️

1. Download or clone the repository
2. Open `login.html`
3. Sign in to access the homepage
